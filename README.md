# 다이아몬드 게임 · DiamondWebs (PWA)

별 모양(6각 성형) 보드에서 빨강·노랑·파랑 말들을 정반대편 진영으로 옮기는 추억의 **다이아몬드 보드게임** 오프라인 설치형 PWA입니다.

## 주요 기능
- **정통 121칸 6각 별 모양 보드**: 3인전(빨강·노랑·파랑) 및 2인전(빨강·파랑) 지원
- **10말 표준 & 15말 전통 모드**: 왕말(👑) 표시 및 10말/15말 선택 가능
- **연속 점프 & 경로 미리보기**: 한 턴 다단 점프 경로 시각화, 단계별 점프 애니메이션, 힌트(💡), 무르기(↩️)
- **3단계 AI & 패스 앤 플레이**: 초급/중급/고급 AI 및 친구·가족과 한 기기에서 대결
- **설치형 오프라인 PWA**: 모바일·태블릿 가로/세로(`orientation: "any"`) 최적화, 터치 롱프레스 방지, Web Audio 효과음 및 한국어 음성 안내(TTS)
